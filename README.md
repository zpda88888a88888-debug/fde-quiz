# FDE 刷题工具

IITC「人工智能应用 FDE 工程师」备考刷题页，纯静态、零依赖，手机与电脑都能用。

## 功能

- **200 道客观题**：单选 80 / 多选 40 / 判断 80，内置在 `questions.js`，打开即用
- **答题即判**：答对自动进入下一题；答错停留一次并展示正确答案与解析
- **逐题解析**：每道题都带解析（200 题全覆盖）
- **考点标签**：13 类考点（知识库与 RAG、Dify 工作流、模型原理等），题目上显示标签
- **错题集**：答错的题自动进入，**不会自动移出**
  - 累计答对满 3 次时弹框询问，点「确定」才移除
  - 也可在题目下方点「移出错题集」手动移除
  - 错题集里的题保持可重做
- **错题分布**：按考点统计错题数，点标签可只看该考点
- **随机组卷**：输入题量（默认 50）随机抽题，随时可回到全题库
- **进度持久化**：答题记录、错题、题池、筛选状态都存在浏览器 localStorage，刷新不丢

## 使用

直接双击 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

手机上打开部署地址即可（支持 iOS Safari / Android Chrome）。

## 自定义题库

「📂 换题库」上传 JSON，格式：

```json
[
  {
    "id": 1,
    "type": "single",
    "tag": "F 知识库与RAG",
    "question": "题干",
    "options": ["选项A", "选项B", "选项C", "选项D"],
    "answer": 1,
    "explanation": "解析"
  }
]
```

- `type`：`single` 单选 / `multiple` 多选 / `judge` 判断
- `answer`：单选与判断填**索引数字**；多选填**索引数组**
- 判断题用 `options: ["正确", "错误"]` + `answer: 0|1`
- `tag`、`explanation` 可省略

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`
2. 访问 `https://<用户名>.github.io/<仓库名>/`
